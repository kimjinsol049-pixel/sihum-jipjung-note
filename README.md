# 시험대비집중노트

자료를 넣으면 핵심을 정리해 주고, 그 자료에서만 문제를 내고, 정답과 해설을 자료의 원래 위치까지 연결해 주는 학습 도구의 **디자인 시안**입니다.

의존성 없는 단일 HTML 파일입니다. 받아서 브라우저로 열면 바로 동작합니다.

```
sihum-jipjung-note.html      본 시안 — 클릭되는 프로토타입 (8화면)
exam-prep-directions.html    작업 초반의 디자인 방향 시안 3종 비교
```

---

## 화면

| # | 화면 | 하는 일 |
|---|------|---------|
| 01 | 자료 넣기 | PDF·이미지·필기 사진·텍스트 업로드, 단계별 처리 상태 |
| 02 | 자료별 정리 | 자료 하나의 목차·핵심 개념·원문 발췌·키워드 |
| 03 | 전체 정리본 | 과목의 모든 자료를 한 편으로 합친 정리본 |
| 04 | 과목 서랍 | 자료별 회독 수, 마지막으로 본 위치, 정답률 |
| 05 | 문제 풀이 | 네 가지 문항 유형, 유형·문항 수 선택 |
| 06 | 정답 & 해설 | 채점 결과, 틀린 문항은 해설이 펼쳐진 채로 시작 |
| 07 | 오답 노트 | 여러 번 틀린 문항 우선, 선택한 문항만 재출제 |
| 08 | 취약점 분석 | 정답률이 낮은 개념과 **그 이유** |

모바일은 문제 풀이와 정답·해설 두 화면을 390×844로 함께 넣었습니다.

## 동작하는 것

- **문항 유형 4종** — 객관식(숫자 키 선택), OX(`O`/`X` 키), 단답형(띄어쓰기·표기 차이 허용), 서술형(채점 기준 3개 대조 + 모범답안)
- **과목 전환** — 상단 탭으로 바꾸면 자료·정리본·문항·취약점 분석이 모두 따라 바뀜
- **근거 링크** — 해설에서 누르면 정리본의 해당 개념으로 이동하며 강조 표시
- **재출제** — 오답 노트에서 고른 문항, 또는 취약 개념 문항만 묶어 한 세트로
- **라이트/다크** — 기기 설정을 따르고, 오른쪽 위 버튼으로 고정 가능
- **키보드** — `1`~`7` 화면 이동, `Enter` 채점, `N` 다음 문항

## 전체 정리본의 두 가지 규칙

1. **빠뜨리지 않는다.** 각 단원이 원문의 몇 쪽을 덮는지 계산해서, 자료별 커버리지를 막대로 보여줍니다. 한 구간이라도 비면 빨간 막대로 표시됩니다.
2. **줄이는 건 보여주는 양뿐.** `핵심만 / 보통 / 빠짐없이` 밀도 조절은 화면에 띄울 분량만 정하고, 접힌 줄은 "지워진 것이 아닙니다"라고 명시한 채 남습니다.

## 샘플 데이터에 대해

경제학원론·세계사·통계학 세 과목에 각 12문항, 총 36문항과 정리본이 들어 있습니다. **문항과 해설의 내용은 실제로 맞는 내용**으로 작성했습니다.

정답률·회독 수·오답 횟수 같은 숫자는 화면이 실제로 쓰일 때의 모습을 보이기 위한 예시 값입니다. 서술형 채점도 시안에서는 예시 결과가 고정으로 표시됩니다 (화면에도 그렇게 적혀 있습니다).

## 아직 정하지 않은 것

- 정리본의 중요도를 사용자가 직접 올리고 내릴 수 있게 할지
- 자료 업로드 용량·형식 제한
- 여러 자료를 묶어 모의고사로 낼지
